# SQL & Python Data Analysis Practice

Repositorio de práctica y proyectos de análisis de datos utilizando SQL, Python y Power BI.

Actualmente incluye ejercicios orientados al desarrollo de habilidades en análisis de datos y un proyecto de análisis de ventas utilizando AdventureWorks2025.

## Contenido

### 01. Práctica SQL

Ejercicios de SQL para reforzar consultas, funciones, subconsultas, CTE, joins y funciones de ventana.

[Ver práctica SQL](./01-practica-sql/)

### 02. Práctica Python

Ejercicios de Python para reforzar fundamentos de programación y manipulación de datos.

[Ver práctica Python](./02-practica-python/)

### 03. Proyecto AdventureWorks

Proyecto de análisis exploratorio de ventas utilizando SQL, Python y Power BI a partir de la base de datos AdventureWorks2025.

El proyecto incluye análisis de ventas, órdenes, canales y productos, además de un dashboard desarrollado en Power BI.
