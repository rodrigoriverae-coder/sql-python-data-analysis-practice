# Práctica Python

Colección de ejercicios realizados para reforzar fundamentos de programación en Python y desarrollar habilidades útiles para el análisis de datos.

## Contenido

### Learning

Ejercicios orientados al aprendizaje de conceptos fundamentales de Python, incluyendo:

- Variables y tipos de datos.
- Operadores.
- Strings.
- Listas, tuplas, sets y diccionarios.
- Condicionales.
- Bucles.
- Funciones.
- Clases.
- Manejo de excepciones.
- Módulos.
- List comprehensions.
- Funciones lambda y funciones de orden superior.

### Practice

Ejercicios prácticos realizados para aplicar y reforzar los conceptos aprendidos mediante diferentes problemas y ejemplos.

Algunos ejercicios también incluyen visualizaciones y manejo de estructuras de datos.
