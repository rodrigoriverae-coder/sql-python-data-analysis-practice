# Práctica SQL

Colección de ejercicios realizados para reforzar diferentes conceptos de SQL aplicados al análisis y manejo de datos.

## Temas practicados

- Consultas y filtros.
- Funciones de agregación.
- CASE WHEN.
- JOIN y LEFT JOIN.
- Subconsultas.
- Common Table Expressions (CTE).
- Funciones de ventana como RANK(), ROW_NUMBER() y LAG().
- Manipulación de fechas.
- Manipulación de texto.
- Uso de COALESCE para valores nulos.
- Agrupaciones y cálculos sobre ventas.

## Ejercicios

Los scripts se encuentran organizados y numerados dentro de la carpeta `ejercicios`, desde conceptos básicos hasta ejercicios que combinan diferentes funciones de SQL.
