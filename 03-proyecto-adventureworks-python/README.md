# Análisis Exploratorio de Ventas y Estacionalidad - AdventureWorks

## Descripción del Proyecto
Este proyecto consiste en un análisis exploratorio de datos y procesamiento ETL sobre los datasets de ventas de AdventureWorks2025, extraídos de SQL Server. El objetivo principal es procesar datos, corregir inconsistencias de formato y evaluar la estacionalidad del negocio junto con la evolución del ticket promedio.

---

## Tecnologías Utilizadas
* **Lenguaje:** Python
* **Librerías principales:**
  * `pandas` (ETL, limpieza y agregaciones)
  * `matplotlib` & `seaborn` (Visualización de datos)
* **Entorno de trabajo:** Google Colab
* **Control de versiones:** GitHub
